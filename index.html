Experience principles

Designed for a smile, not a workflow.

Bright, celebratory, mobile-first UI with short actions, visible progress and a strong social-sharing loop.

  • Sender: request → choose package → recruit → personalize → share.
  • Contributor: discover → accept → record → review → earn.
  • Recipient: open link → watch → react → create own.
Prototype scope

25+ connected states

Navigation, forms, package choices, demo payments, clip acceptance, simulated uploads, review, sharing, wallet, privacy, failures and recovery paths.

Demonstration only: payment, identity verification, actual video capture/encoding, global matching and message delivery require backend integrations.
